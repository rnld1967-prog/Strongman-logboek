# Strongman logboek

Trainingslogboek voor Training A (zondag) en Training B (donderdag), met plaatjes per oefening, pauzetimer en voortgang.

Open de app op je telefoon via GitHub Pages en zet hem op je beginscherm.
Je trainingen worden alleen op je telefoon bewaard; maak af en toe een reservekopie via het tabblad *Voortgang*.
